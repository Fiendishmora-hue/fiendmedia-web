# fiendmedia-web

Home page and privacy policy of the Fiendmedia Google OAuth app, served by GitHub Pages:

- https://fiendishmora-hue.github.io/fiendmedia-web/
- https://fiendishmora-hue.github.io/fiendmedia-web/privacy.html

Google requires both links before an OAuth app can leave the "Testing" status,
whose refresh tokens expire every seven days. The tool itself lives in a private repository.
